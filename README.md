# 2D Ship Battle Game

A simple arcade-style naval shooter built with Python and Pygame.  
Control your ship, shoot enemy ships, and survive as long as possible.

---

## Features

- Player ship movement
- Shooting system
- Enemy ships
- Collision detection
- Score tracking

---

## Built With

- Python
- Pygame
